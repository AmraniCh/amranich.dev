# amranich.dev

Source code of my personal website: [amranich.dev](https://amranich.dev).

Built with [Astro](https://astro.build) and deployed to GitHub Pages.

## Run locally

```bash
corepack pnpm install
corepack pnpm dev
```

Add a `GITHUB_TOKEN` in `.env` to avoid the GitHub API rate limit.

## Content

- `public/0user.json`: profile, projects, open source and resume
- `src/content/presentations.yaml`: presentations
